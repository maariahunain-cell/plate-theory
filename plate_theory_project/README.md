# Plate Theory — Food Ordering Store

A React + Vite food-ordering storefront with a complete food-first visual identity and menu.

## Brand direction
- **Name:** Plate Theory
- **Positioning:** A modern neighbourhood flavour lab for pizza, burgers, momos, bowls, sides, desserts and drinks.
- **Palette:** warm cream, deep herb green and tomato red.
- **Typography:** DM Sans with Playfair Display for expressive headlines.

## Run locally
1. Install Node.js (18+ recommended).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Production build
Run `npm run build`.

## Notes
- Product photography is loaded from Unsplash image URLs and requires an internet connection.
- Authentication, cart and order data use browser localStorage in this demo starter. This is not production-grade authentication or payment processing.
- The payment flow is a demonstration only; connect a trusted payment provider and backend before accepting real orders.
- Replace the sample contact address, delivery coverage, pricing, allergen information and menu details with verified business information before launch.
